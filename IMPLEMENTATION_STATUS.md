# Состояние локальной реализации

Дата: 16.11.2026. Основание — ONLINE_SPEC.md 1.0.

## Реализовано

- FastAPI `/`, `/health`, `/run`; запуск на Python 3.11 через `start.sh`.
- Явный адаптер JSON pointers и локальная проверка входной/выходной схем.
- Сохранение типов исходных ID, группировка по вопросу/пользователю/контексту,
  общий CitationSet, сборка в исходном порядке.
- Индекс текущего корпуса: BM25, RU/EN stemming, тезаурус, char n-grams,
  семантические кандидаты и RRF с сохранением каналов.
- LLM-планировщик: каталог всего корпуса, самостоятельный вопрос, RU/EN terms,
  проверка group/source keys, общий бюджет всей стадии, частичный repair.
- Генерация трёх персон по общим исходным фрагментам, опорные цитаты,
  структурная проверка, hard veto, проверка совпадающих текстов.
- Ограниченные retries/repair, изоляция ошибки группы, мягкие запасные ответы
  с реальной навигационной ссылкой; небольшой extractive путь для определений.
- Общий gateway: модель/ключ из env, один клиент, no redirects, limiter,
  concurrency, абсолютный deadline, учёт неизвестного расхода после timeout,
  остановка вызовов после ошибки авторизации или перерасхода usage.
- Single-flight и ограниченный кэш с HMAC-ключом области авторизации.
- Словарь токенизатора на диске с SHA-256; runtime ничего не скачивает.
- Локальный CLI, синтетический набор, структурный evaluator и инструкции README.

## Открытые интеграционные проверки

Официальных схем, реального dev-корпуса и опубликованных judge prompts в проекте
пока нет. `contracts/profiles/local_example.json` — явно синтетический профиль,
сетевой online-прогон с ним запрещён. Необходимо подтвердить реальные mappings,
поддержку proxy-параметров, токенизацию актуальной модели, качество S/G/V,
latency/p95, память на настоящих данных и ответ `valid:true` официального validate.

Финальный интерактивный чат/клиент, команда добавления статьи и измерение цены
новой персоны не входят в этот этап реализации онлайн-бэкенда. Для них оставлено
общее ядро и контекст в модели запроса; готовый чат не заявляется.

Ничего не опубликовано, не задеплоено, не отправлено в validate и не сохранено
в удалённый репозиторий. Реальная LLM не вызывалась. Сетевые тесты используют
только MockTransport; отдельный запрос публичного OpenAPI не содержал токенов,
исходного кода, данных команды или ответов.

- Официальный контракт получен: `GET /case/4/getData`, схемы `Case4Dataset`/`Case4Answers`, dev `case4-dev-v2` (20 статей, 60 записей, 20 групп, reference).

- Стенд: деплой из `main`, `/` и `/health` 200, dev `/run` 200, 60 ответов, 30 отказов, память ~45 МБ.
