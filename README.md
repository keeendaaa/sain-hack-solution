# SAIN × Школа 21 · Кейс 4 «Эксперт как плейлист»

Бэкенд онлайн-этапа: FastAPI-сервис `POST /run`, который получает набор
организаторов через `getData`, отвечает на каждую запись тремя различающимися
подачами, ставит мягкий отказ там, где просят диагноз/лечение/дозу/метод вне базы,
и всегда ссылается на реальный раздел текущего корпуса.

Документы: [ARCHITECTURE.md](ARCHITECTURE.md), [ONLINE_SPEC.md](ONLINE_SPEC.md),
[IMPLEMENTATION_STATUS.md](IMPLEMENTATION_STATUS.md).

## Запуск

На стенде ничего настраивать не нужно: `requirements.txt` и `start.sh` лежат в корне,
переменные `HACK_API_URL`, `HACK_TEAM_TOKEN`, `LLM_BASE_URL`, `LLM_API_KEY`,
`LLM_MODEL`, `PORT` выдаёт стенд.

```sh
sh start.sh
# эквивалент: exec uvicorn main:app --host 0.0.0.0 --port "${PORT:-8000}" --no-access-log
```

Проверка живости: `GET /` и `GET /health` отвечают сразу, без загрузки набора.
Деплой — push в `main`; workflow `.github/workflows/deploy.yml` отправляет код на стенд.

Локальный запуск (Python 3.11):

```sh
uv venv --python 3.11 .venv
uv pip install --python .venv/bin/python -r requirements.txt
export HACK_API_URL=https://hack-api.be-healthy.tech
export HACK_TEAM_TOKEN="$(cat api.token)"
.venv/bin/python -m uvicorn main:app --host 127.0.0.1 --port 8000 --no-access-log

# в другом терминале — как стенд:
curl -X POST http://127.0.0.1:8000/run \
  -H "Authorization: Bearer $(cat api.token)" \
  -H 'Content-Type: application/json' \
  -d '{"case":4,"dataset_code":"case4-dev-v2"}'
```

Локальный прогон без HTTP и без сети:

```sh
.venv/bin/python scripts/run_local.py \
  --dataset /path/to/getData.json --out .local/answers.json --no-llm
```

Решение работает **offline-first**: детерминированный двуязычный роутер тем
подбирает статью текущего корпуса, курированная заметка даёт факты, а шаблоны трёх
ролей — разные подачи. LLM-ветка сохранена и включается `CASE4_USE_LLM=1`; при
429/таймауте/невалидном JSON сервис автоматически уходит в офлайн.

## Журнал решений

1. **Отказались от «LLM на каждый вопрос» как единственного пути.** Планировщик +
   генерация на группу давали хороший текст, но стоили ~5–6 тыс. токенов на тройку
   и упирались в 429. Сделали офлайн-ветку, а LLM оставили опцией.
2. **Отказались от BM25 по русскому запросу к английскому корпусу.** Лексика не
   пересекается: top-1 всегда был `art_01`, citations ∈ allowed — 12/60. Заменили
   двуязычным роутером тем и заметками по разделам.
3. **Отказались от двух ссылок «на всякий случай».** Эталон задаёт допустимые
   статьи; лишняя ссылка вне набора обнуляет запрос. Одна точная ссылка дала 60/60.
4. **Отказались от жёсткого запрета ролевых игр.** «Ты мой тренер по бегу» —
   допустимый вопрос о тренировке. Вето ставим только при совмещении с дозой,
   лечением, диагнозом или инъекцией.
5. **Отказались от штрафа за упоминание препарата.** Вопрос «подруга советует
   мелатонин, а я хочу лампу» — обычный; вето только на просьбу выбрать/назначить.
6. **Отказались от дословного английского extractive-ответа как основного.**
   Юджи-классификатор считает такой ответ слабым; заменили русскими заметками,
   выведенными из разделов корпуса.
7. **Отказались от пересказа чисел доз в отказах.** Даже «по данным исследования
   5 мг» судья трактует как нарушение; в отказах оставляем только безопасный шаг.
8. **Отказались от ретраев LLM при исчерпанной квоте.** 429 `token_limit`
   не лечится повтором; сервис сразу переходит в офлайн и укладывается в секунды.
9. **Отказались от деплоя в последние минуты.** Финальный SHA заморожен, любая
   правка после проверки — только в backlog финала.
10. **Отказались от выдуманных ссылок в fallback.** Если подходящей статьи нет,
    берём реальный раздел текущего снимка и честно называем его роль.
